# Страницы приложения

Базовый префикс маршрутов — `/isotopes`. На всех страницах отображается общая нижняя навигация `NavBar`.

## Общая навигация

`NavBar` содержит ссылки-иконки без текстовых подписей:

| Ссылка | Иконка | Назначение |
|---|---|---|
| `/isotopes/feed` | `/icons/home.svg` | Лента изотопов |
| `/isotopes/catalog` | `/icons/grid.svg` | Каталог изотопов |

Пункты `add` и `auth` в `navigation.ts` закомментированы и в навигации не отображаются.

## Маршруты

| Маршрут | Страница |
|---|---|
| `/isotopes/feed` | Лента: первый опубликованный изотоп |
| `/isotopes/feed/:isotopeId` | Лента: конкретный изотоп |
| `/isotopes/feed/:isotopeId?next=true` | Лента: следующий опубликованный изотоп, если следующего нет — первый опубликованный |
| `/isotopes/catalog` | Каталог опубликованных изотопов |
| `/isotopes/catalog?maxHalfLifeExponent=N` | Каталог с ограничением по максимальному периоду полураспада |
| `/isotopes/add` | Страница добавления изотопа на основе черновика; в навигации скрыта |

## Страница ленты изотопа

Маршруты: `/isotopes/feed`, `/isotopes/feed/:isotopeId`.

На странице отображаются:

- фоновое видео изотопа с fallback-видео; видео воспроизводится автоматически, зациклено и без звука;
- оверлей;
- мета-блок с лайком, признаком α-распада, периодом полураспада и кнопкой перехода к следующему изотопу;
- название изотопа;
- описание с переключателем «Подробнее» / «Скрыть».

### Кнопки и ссылки

| Элемент | Действие |
|---|---|
| Кнопка лайка `LikeToggle` | Переключает локальное состояние лайка и изменяет счётчик |
| Ссылка «следующий» с иконкой `chevrons-right.svg` | Переходит на `/isotopes/feed/{id}?next=true` |
| Чекбокс в блоке описания | Переключает отображение «Подробнее» / «Скрыть» |

### Поля

| Поле | Тип | Назначение |
|---|---|---|
| Чекбокс описания | `checkbox` | Показ полного или сокращённого описания |

Дополнительно в мета-блоке выводятся:

- признак α-распада: иконка `check.svg` или `cross.svg`;
- период полураспада `T½` в компактном виде, полное значение — в `title`.

## Страница каталога

Маршрут: `/isotopes/catalog`.

Страница содержит форму поиска по максимальному периоду полураспада и список карточек изотопов.

### Форма поиска

Форма отправляется методом `GET`.

| Поле / элемент | Атрибуты | Назначение |
|---|---|---|
| Ползунок `maxHalfLifeExponent` | `type="range"`, `min="-1"`, `max="27"`, `step="1"` | Максимальный период полураспада в виде степени 10 |
| Кнопка «Найти» | `type="submit"` | Отправляет форму с выбранным значением |

Особенности:

- значение `-1` означает отсутствие ограничения и показывает подсказку `T½, макс. (нс)`;
- при значении `N >= 0` отображается `10^N нс.`;
- подписи ползунка: `0 нс.` и `1e27 нс.`.

### Карточка изотопа

Карточка содержит изображение, название, период полураспада и блок лайка.

| Элемент | Действие |
|---|---|
| Ссылка-изображение | Переход на `/isotopes/feed/{id}` |
| Ссылка-название | Переход на `/isotopes/feed/{id}` |
| Кнопка лайка `LikeToggle` | Переключает локальное состояние лайка и изменяет счётчик |
| Кнопка удаления с иконкой `bin.svg` | Отображается только при `isAuthor`; отправляет `POST` на `/isotopes/{id}/delete` |

## Страница добавления изотопа

Маршрут: `/isotopes/add`.

Страница доступна по прямому URL, но не отображается в `NavBar`. Загрузчик берёт черновик из `fetchDraft()`; если черновика нет, возвращается `404` с текстом «Черновик не найден».

Форма:

- метод `POST`;
- `encType="multipart/form-data"`.

### Поля формы

| Поле | `name` / `id` | Тип | Ограничения и значения |
|---|---|---|---|
| Видео | `video` / `isotope-video` | `file` | `accept="video/*"`, обязательно; есть превью `FallbackVideo` |
| Фото | `image` / `isotope-image` | `file` | `accept=".png, .jpg, .jpeg"`, обязательно; есть превью `FallbackImage` |
| Название изотопа | `name` / `isotope-name` | `text` | `placeholder="Название"`, `minLength=5`, `maxLength=20`, обязательно; значение по умолчанию — `isotopeDraft.name` |
| Период полураспада | `halfLife` / `isotope-half-life` | `text` | `inputMode="numeric"`, `pattern="[0-9]+"`, `maxLength=27`, обязательно; значение по умолчанию — `isotopeDraft.halfLife?.toString()` |
| α-распад | `name` не задан | `checkbox` | `defaultChecked={isotopeDraft.isAlpha ?? false}`; подпись «α-распад», пояснение «Происходит α-распад» |
| Описание | `description` / `isotope-description` | `textarea` | `placeholder="Описание"`, `maxLength=200`, обязательно; значение по умолчанию — `isotopeDraft.description ?? ''` |

### Кнопки

| Элемент | Действие |
|---|---|
| Кнопка «Сохранить» | `type="button"`; в текущей реализации обработчик отправки формы не подключён |

## Общие элементы интерфейса

- `LikeToggle` — кнопка с иконкой сердца и счётчиком лайков; поддерживает горизонтальное и вертикальное отображение.
- `FallbackImage` — изображение с fallback-картинкой при отсутствии `src` или ошибке загрузки.
- `FallbackVideo` — видео с fallback-видео при отсутствии `src` или ошибке загрузки.
- `Field` — обёртка для `label` и `input`.
- `Textarea` — обёртка для `label` и `textarea`.
